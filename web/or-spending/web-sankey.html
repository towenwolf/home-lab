Where Does Your $1 Go?

Every transaction in Oregon's public spending data, normalized to show exactly how a single tax dollar flows from the state treasury to its final destination.

Query · Normalize spending to $1
-- How is $1.00 of Oregon tax revenue allocated?
WITH total AS (
  SELECT SUM(expense) AS grand_total FROM oregon_spending
),
per_dollar AS (
  SELECT
    agency_name,
    budget_class_name,
    expend_class_name,
    ROUND(SUM(expense) / grand_total, 4) AS cents_per_dollar
  FROM oregon_spending, total
  GROUP BY agency_name, budget_class_name, expend_class_name, grand_total
  ORDER BY cents_per_dollar DESC
)
SELECT *,
  FORMAT(cents_per_dollar * 100, '0.00¢') AS per_dollar_display
FROM per_dollar;
